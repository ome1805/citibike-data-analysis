## 🛠️ Tech Stack
* **Python**: Core programming environment used within Jupyter Notebook.
* **DuckDB**: Analytical query engine to process and aggregate nearly 3 million CSV rows directly from disk in seconds.
* **SQL**: Querying including conditional categorization (`CASE WHEN`), Common Table Expressions (`WITH`), and duration arithmetic (`DATE_DIFF`).

## 📊 Key Findings
* **Total Volume**: Processed a total of **2,945,753 trips** across New York City for March 2026.
* **Commuter vs. Leisure Patterns**:
  * **Annual Members**: Averaged **11.13 minutes** per ride, reflecting utility-driven commuting.
  * **Casual Riders**: Averaged **20.43 minutes** per ride, reflecting longer leisure and recreational trips.
* **Peak Hours**: Commuter spikes concentrate around standard weekday morning (8–9 AM) and evening (5–6 PM) rush hours.
